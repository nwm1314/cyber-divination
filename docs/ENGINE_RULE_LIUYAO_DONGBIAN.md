## 1. 问题陈述（改动前事实，可复核）

`src/lib/liuyao/analyze/dongbian.ts` 的 import 只有三项
（`types/liuyao`、`cast/yao`、`analyze/liuqin`），**未引入 `kongwang` / `yuepo`**。

其 `analyzeDongBian()` 对每个动爻只做一件事：

```
wuxingRelation(本爻五行, 化爻五行) → 比和|动生化|动克化|化生动|化克动
```

**后果（客观、无需流派即可判定）**：

- 「**寅化卯**」（木化木，**进神**）与「**寅化午**」（木化火，动生化）
  当前被归入不同类，但「**寅化卯**」与「**卯化寅**」（**退神**）
  都落入 `比和`，**无法区分进神与退神**——同支不同位。
- 「化空」「化破」完全不表达：化爻是否落旬空、是否被月建冲破，
  代码从未查询 `xunKong` / `yueJian`。
- 「化冲」「化合」不表达：化爻与本爻是否构成六冲/六合。

`src/lib/liuyao/analyze/scope.ts:9-12` 亦**主动声明**了这些未覆盖项：

```
LIUYAO_UNSUPPORTED_RULES = [
  "旺相休囚完整表、墓绝",
  "三合、进退神、反伏吟全量状态机",
  ...
]
```

即：这是**已知且已声明**的缺口，不是隐藏缺陷。

## 2. 流派声明

### 2.1 本引擎既有定位（`data/sources.ts:31-32`）

```
school: "学习向·表驱动 v1；非单一师承全书；规则 id 可追溯"
```

装卦层另声明：时间法为 `meihua-time-to-najia`（梅花先天数 + 纳甲混合，
**非纯纳甲**），铜钱/手动为 `najia-coins` / `najia-manual`。

### 2.2 进退神的流派口径

「进神 / 退神」依**地支在十二支序列上的前后位移**判定，属纳甲六爻的
通行规则（《增删卜易》《卜筮正宗》系）：

| 情形 | 判定 | 含义（中性表述） |
|---|---|---|
| **进神** | 化爻地支 = 本爻地支**顺行**（子→丑→寅…），且**同五行** | 力量同向推进 |
| **退神** | 化爻地支 = 本爻地支**逆行**（寅→丑→子…），且**同五行** | 力量回撤 |
| 化进（异支同五行，顺行） | 如 寅→卯、巳→午、申→酉、亥→子、丑→辰、未→戌 | — |
| 化退（异支同五行，逆行） | 如 卯→寅、午→巳、酉→申、子→亥、辰→丑、戌→未 | — |

**关键约束（本引擎采用）**：进退神**仅在化爻与本爻同五行时**成立。
五行不同则是生克关系（已有 `wuxingRelation` 覆盖），不叠加进退。

> 注意：「同五行地支」在十二支中只有成对出现的情形才构成进退：
> 寅卯（木）、巳午（火）、申酉（金）、亥子（水）、辰戌丑未（土）。
> 其中土有四支，本引擎**只对相邻位移**判定进退，跨支（如 辰→未）不判进退，
> 因为土居四维、跨支位移的"进退"在流派间无共识。这是**保守选择**：
> 宁可少判，不可错判。

### 2.3 空亡 / 月破 的口径

沿用本引擎已有实现（不新增规则）：

- **旬空**：`kongwang.ts` 的六十甲子旬空表（`甲子旬空戌亥` …）
- **月破**：`yuepo.ts` 的「爻支冲月建」（六冲表）
- **日冲**：`yuepo.ts` 的「爻支冲日支」

本改动**只把它们接到动变层**，不修改任何判定表。

### 2.4 冲合的口径

沿用 `yingqi.ts:156-168` 的六冲表。六合表新增于本文件，
取通行配对：子丑、寅亥、卯戌、辰酉、巳申、午未。

### 2.5 明确的非目标

- ❌ 不做「反伏吟」全量状态机（需本卦/变卦全盘比对，独立议题）
- ❌ 不做「旺相休囚完整表、墓绝」
- ❌ 不做「三合局」
- ❌ 不做「暗动与飞神细断」
- ❌ 不改动任何既有判定表（旬空表/六冲表/纳音/六亲全不动）
- ❌ 不改 `wuxingRelation` 的五行生克结果（只在其上**叠加**新标签）

## 3. 改动方案

### 3.1 类型扩展（向后兼容）

`DongBianItem` 增加 optional 字段：

```ts
/** 进退神（仅同五行且相邻位移时判定） */
jintui?: "进神" | "退神";
/** 化爻空破状态（需占时；无占时为 undefined） */
huaKong?: boolean;   // 化爻落旬空
huaPo?: boolean;     // 化爻被月建冲破
/** 化爻与本爻的地支关系 */
chongHe?: "化冲" | "化合";
/** 本爻自身空破（需占时） */
benKong?: boolean;
benPo?: boolean;
```

全部 optional ⇒ 旧数据/旧快照可解析，`summary` 文案向后兼容。

### 3.2 判定顺序（叠加而非替换）

对每个动爻：

1. 五行关系（既有 `wuxingRelation`）→ `relation` / `huitou`
2. **进退神**：同五行 + 相邻位移 → `jintui`
3. **空破**：查 `xunKong`（化爻/本爻）与 `yueJian`（月破）
4. **冲合**：本爻支 ↔ 化爻支

`summary` 按「本爻 → 化爻（关系 + 回头 + 进退 + 冲合 + 空破）」重组，
并保持**中性表述**（不出现吉凶恐吓，符合 `sources.ts:34` 的 excluded 约定）。

### 3.3 scope 声明同步

`scope.ts` 的 `LIUYAO_UNSUPPORTED_RULES` 需**移除已实现项**
（进退神、空破冲合），保留仍未实现项（反伏吟、三合、墓绝、暗动）。

## 4. 差异报告（改动前 → 改动后）

以「本爻支 → 化爻支」为输入（同五行情形）：

| 本爻 | 化爻 | 改动前 | 改动后 |
|---|---|---|---|
| 寅(木) | 卯(木) | `比和` | `比和` + **进神** |
| 卯(木) | 寅(木) | `比和` | `比和` + **退神** |
| 巳(火) | 午(火) | `比和` | `比和` + **进神** |
| 子(水) | 亥(水) | `比和` | `比和` + **退神** |
| 辰(土) | 未(土) | `比和` | `比和`（跨支不判进退，保守） |
| 寅(木) | 午(火) | `动生化` | `动生化`（不变） |
| 子(水) | 午(火) | `比和`?→实际 `动克化` | `动克化` + 冲合标记 |

> 表格中「冲合」仅在**同支相冲/相合**时出现；子午既冲又属不同五行，
> 故会同时带 `chongHe="化冲"`。

### 4.1 行为差异的可观察点

| 场景 | 改动前 | 改动后 |
|---|---|---|
| 进神/退神 | 不可见 | `jintui` 字段 + 文案 |
| 化爻落空 | 不可见 | `huaKong=true` + 文案「化空」 |
| 化爻月破 | 不可见 | `huaPo=true` + 文案「化破」 |
| 化冲/化合 | 不可见 | `chongHe` 字段 + 文案 |
| 静卦 | 中性说明 | **不变** |
| 五行生克 | 五分类 | **不变**（仅叠加） |

## 5. 验证方法

### 5.1 必须先补的覆盖度测试（B-23）

`REVIEW_ENG_ENGINE.md` B-23 指出**变卦覆盖度 0%**。本改动先补：

- **4096 变卦穷举**：64 本卦 × 64 变卦 = 4096 组合
  （等价于 6 爻各自静/动共 2^6=64 种动爻模式 × 64 本卦）
- 断言：全部组合可装卦且不抛错；六亲/世应/动变分析均产出结构化结果
- 断言：进退神判定在同五行相邻位移时为真，跨支/异五行为假

### 5.2 规则正确性测试

- 进神：寅→卯、巳→午、申→酉、亥→子（逐对）
- 退神：卯→寅、午→巳、酉→申、子→亥（逐对）
- 不判进退：异五行、土跨支（辰→未、未→丑 等）
- 空破：构造已知旬空日，断言 `huaKong`
- 冲合：构造六冲/六合配对，断言 `chongHe`
- 无占时：`huaKong`/`huaPo` 为 undefined（不臆断）

### 5.3 未验证项（如实标注）

- 进退神、空破、冲合的**流派归属**为本引擎声明的
  「学习向·表驱动 v1」，**未经外部命理师审校**。
- 各条规则的具体**应期/吉凶断语**不在本改动范围——
  本改动只做**结构化标注**，不下吉凶结论（符合 `sources.ts:34`）。
- 土支跨支是否判进退，流派无共识，本引擎**保守不判**并已注明。

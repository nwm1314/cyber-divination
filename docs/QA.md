- [ ] 分步表单可填写姓名、阳历/农历生日（至少其一）、性别（必填）、出生时间（可选跳过）、出生地、经度（真太阳时）
- [ ] 时辰未知时可不填，提示「六字盘」

## 生产冒烟（上线检查表 · T73）

> **用途**：生产/预发部署后，主 Agent 或值班人按序勾选；**任一项失败且无法热修 → 触发回滚**。  
> **部署与环境变量**：见 [`docs/DEPLOY.md`](./DEPLOY.md)（T72）。  
> **路由对照**（以 `src/app` 为准）：

| 路径 | 说明 |
|------|------|
| `/` | 落地页 |
| `/chart/new` | 填盘表单 |
| `/chart/[id]` | 命盘页 |
| `/chart/[id]/reading` | 解读报告页 |
| `/chart/[id]/calibrate` | 校准页 |
| `/charts` | 本地档案列表 |
| `/settings` | 设置 |
| `/share/[token]` | 分享只读页 |
| `POST /api/reading` | LLM 解读（可回落模板） |
| `POST /api/share` | 创建分享快照 |
| 全局 `not-found` / `error` | 404 / 渲染错误页 |

**冒烟前准备**

- [ ] 生产环境变量已按 DEPLOY 配置：`SHARE_STORE_DRIVER=upstash`，且 `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` 有效（**禁止**生产用 `local`）
- [ ] `LLM_*`：本轮冒烟需覆盖「有 Key」与「无 Key」两态（可先无 Key 测回落，再临时注入 Key 测真 LLM，或两套环境各跑一次）
- [ ] 记录当前发布版本标识（Git SHA / 平台 Deployment ID），便于回滚
- [ ] 浏览器无痕窗口 + 可选第二设备，模拟无登录访问

### A. 排盘冒烟

- [ ] 打开 `/`：页面 200，赛博国潮视觉正常，免责声明可见
- [ ] 点「开始排盘」→ `/chart/new` 可加载
- [ ] 填写最小合法档案（姓名、性别、阳历生日；时辰可跳过）并提交
- [ ] 进入 `/chart/[id]`：四柱表渲染；未知时辰显示「时柱未知」
- [ ] 硬刷新 `/chart/[id]`：盘仍可读（本地档案未丢）
- [ ] 同一输入再排一次：四柱与上次一致（确定性）

**失败判据（触发回滚或阻断发布）**：落地/填盘/命盘任一路由 5xx、白屏、无法提交、四柱错乱或与已知金标准明显不符。

### B. 模板解读冒烟

- [ ] 从命盘进入 `/chart/[id]/reading`
- [ ] 默认或切换为**规则模板**模式：8 章齐全（日主→十神→五行→格局→大运→流年→校准→建议）
- [ ] 报告底部免责 + 结束句「命理分析仅供参考，人生在于自身的努力和选择。」
- [ ] 通俗/专业切换可用（不要求文案完美，要求不崩、章节不空）

**失败判据**：报告页 5xx/白屏、章节缺失、无法离开模板模式以外的主路径。

### C. LLM 解读冒烟（有 Key / 无 Key）

**C1 · 无 `LLM_API_KEY`（或 Key 故意留空）**

- [ ] `GET /api/reading/status` 返回 `{ data: { llmConfigured: false } }`（无 Key 明文）
- [ ] 报告页 **LLM 按钮禁用**，并展示配置说明（指向 `.env.local` / `LLM_*`）
- [ ] 用户无法切到 LLM 再「点后回落」；模板解读仍完整可读
- [ ] 若直接 `POST /api/reading`：不因无 Key 而 5xx（允许 200 + fallback）

**C2 · 已配置有效 `LLM_API_KEY`（及 `LLM_BASE_URL` / `LLM_MODEL`）**

- [ ] 切换 LLM 模式，等待生成完成
- [ ] 返回 8 章结构完整；`mode` 为 LLM 且无意外 fallback（或 fallback 原因可接受，如上游超时后回落模板）
- [ ] 响应头/日志无 API Key 明文泄露（抽查平台日志一条即可）

**失败判据**：有 Key 时持续 5xx 且无法回落；无 Key 时整页不可用；限流误伤导致单次正常请求即 429（配置明显错误）。

### D. 分享创建与打开

- [ ] 在报告页点击「分享」，触发 `POST /api/share`
- [ ] 返回 200，响应含 `token` 与 `url`（形如 `{origin}/share/{token}`）
- [ ] 新开无痕窗口打开该 `/share/[token]`：只读展示四柱 + 签语 + 免责，**无需登录**
- [ ] 姓名默认脱敏（如 `张*` / `王*五` 类），无完整隐私字段外泄
- [ ] 模拟冷启动后再打开同一链接：快照仍在（Upstash 持久；**非**仅本机 `data/shares.json`）
- [ ] （可选）短时连续创建分享：超限返回 **429** 与提示「请求过于频繁」，业务恢复后可再创

**失败判据**：创建 5xx；创建成功但打开 404/空页；生产仍写本地文件导致冷启动丢链；分享页暴露完整敏感信息。

### E. 404 / 错误页冒烟

- [ ] 访问不存在路径（如 `/this-route-does-not-exist-t73`）→ 自定义 404：「页面未找到」，可回首页 / 开始排盘
- [ ] 访问伪造分享链 `/share/00000000-0000-0000-0000-000000000000`（或不存在 token）→ 走 `notFound`，文案提示链接失效/快照不存在
- [ ] （可选）触发一次客户端错误页：全局 `error` 展示「出了点问题」，「重试」「首页」可用，不白屏

**失败判据**：404 变成平台默认英文页且无导航；错误页白屏；分享 miss 返回 500 而非 404。

### F. 冒烟总闸（发布通过条件）

- [ ] A–E 全部勾选通过（C1/C2 至少完成与当前生产配置匹配的一态；**公网正式开放 LLM 前须 C2 通过**）
- [ ] 无 P0 合规回归：落地/报告/分享三处免责仍在
- [ ] 记录冒烟时间、操作人、版本 SHA、结论（通过 / 回滚）

### G. Docker / 容器冒烟（T303）

## 失败回滚（条件与步骤）

### 何时必须回滚

满足**任一**即回滚当前生产部署（或立刻切流量到上一稳定版本）：

| 级别 | 条件 |
|------|------|
| **P0 阻断** | `/`、`/chart/new`、`/chart/[id]` 大面积 5xx 或无法完成排盘 |
| **P0 阻断** | 模板解读不可用（`/chart/[id]/reading` 白屏/5xx，且无可用模板路径） |
| **P0 阻断** | 分享：`POST /api/share` 持续失败，或新链无法打开（含 Upstash 配置错误导致进程 fail-fast / 500） |
| **P0 阻断** | 错误配置导致生产使用 `SHARE_STORE_DRIVER=local`（Serverless 丢数据）且已对外发链 |
| **P0 安全** | 日志/响应泄露 `LLM_API_KEY`、Upstash Token 或用户完整隐私 |
| **P1 可热修** | 仅 LLM 上游故障但模板回落正常 → **可不回滚**，关闭对外 LLM 宣传或临时清空 Key 强制回落 |
| **P1 可热修** | 限流过严导致偶发 429 → 先调大 `RATE_LIMIT_*` 热更配置，观察 10 分钟；仍异常再回滚 |
| **P2 Docker** | 镜像构建失败或 HEALTHCHECK 持续 unhealthy → 检查 Dockerfile / compose.yaml 与依赖；使用上一稳定镜像 tag |
| **P2 Docker** | 容器以 root 运行（`Config.User` 为空或 root）→ 阻断发布，修复 Dockerfile USER 指令后重新构建 |

### 回滚步骤（清单）

1. [ ] **宣布**：在发布频道标注「生产冒烟失败 / 回滚中」，停止继续引流与发版
2. [ ] **平台回滚**：在托管平台（如 Vercel）将 Production 回退到**上一通过冒烟的 Deployment**（或 `git revert` 后重新部署上一 tag）
3. [ ] **环境变量**：若因错误 env 导致故障，先恢复上一组已知良好变量再重部署；**勿**在故障态把 `upstash` 静默改成 `local` 顶生产
4. [ ] **分享数据**：Upstash 内已有 token **不要清空**（回滚代码后旧链仍应可读）；仅当写入了错误 schema 且已确认无用时，再按 DEPLOY 删除策略清理
5. [ ] **验证回滚**：对上一版本重跑本节 **A + B + D + E** 最小集（排盘 → 模板解读 → 创建并打开分享 → 404）
6. [ ] **复盘**：记录失败步骤、日志 `requestId`、根因、是否需修 T70/T71 后再发；修复后重新完整跑 A–F

### 回滚后禁止事项

- [ ] 未通过 A+B+D 最小集前，不重新标「生产可用」
- [ ] 不删除 Upstash 全库「试一下」除非已备份且产品确认
- [ ] 不把含真实 Key 的 `.env` 提交进仓库

## 紫微斗数阶段验收（P2 · T109）

> 验收人逐项勾选；**排盘/装卦 = 确定性引擎（不经 LLM）**；**解读/解卦 = 模板或 LLM**；排盘结果须确定性、可单测

**PRODUCT §12.5 成功标准摘要**

| 标准 | 验收要点 |
|------|----------|
| 同生辰多次排盘一致 | 引擎纯函数；刷新/重排四柱级字段（命宫身宫、十二宫主星）不变 |

| 报告章节结构固定可测 | 固定 8 章 key，模板与 LLM 均可独立完成 |
| 合规同八字 | 娱乐学习、中性建设性、结束固定句；无绝对化承诺 |

### 1. 采集（`/ziwei/new`）

### 2. 看盘（`/ziwei/[id]`）

- [ ] 十二宫宫位盘渲染完整（宫名 + 星曜）
- [ ] **命宫**、**身宫**有明确标识（视觉或文案可辨）
- [ ] 主星/辅星列表可读；爱好者能指出主星落宫
- [ ] 大限 / 流年信息可见（至少摘要级，不要求全流派细则）
- [ ] 通俗 / 专业模式可切换（专业可展开更多字段；通俗不崩、不空盘）
- [ ] 同一输入多次排盘、硬刷新后：命宫身宫与主星落宫**一致**（确定性引擎）
- [ ] 移动端单栏、桌面端布局无严重截断或溢出
- [ ] 可从命盘进入 `/ziwei/[id]/reading`

### 3. 解读（`/ziwei/[id]/reading`）

- [ ] 默认**规则模板**模式：上述 8 章 key/标题齐全，章节非空
- [ ] 可切换 LLM 模式；无 API Key 时自动回落模板并有可理解提示
- [ ] 报告页可切换通俗 / 专业
- [ ] 免责章节或页脚可见；结束语含「命理分析仅供参考，人生在于自身的努力和选择。」（或与全局 `DISCLAIMER` 一致）
- [ ] 模板与 LLM（有 Key）均可独立完成完整报告；结构可测（8 章顺序稳定）

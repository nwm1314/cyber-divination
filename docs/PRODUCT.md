# 赛博八字 · 产品方案 v1

> 依据 [jinchenma94/bazi-skill](https://github.com/jinchenma94/bazi-skill) 能力映射的 Web 产品  
> 仓库：`cyber-divination` · 中文名：**赛博八字**  
> 免责：传统文化学习与娱乐参考，不构成决策依据

---

## 1. 产品一句话

用**专业级八字排盘引擎**排出四柱/大运/流年，再以**规则模板**或**服务端 LLM（典籍约束）**生成可读批命报告；界面为**赛博国潮**，默认通俗、可切专业模式，形成「填盘 → 看盘 → 解读 → 历史校准 → 分享」完整闭环。

### 1.1 与 bazi-skill 的复用原则（硬约束）

规则与解读**尽可能复用** [jinchenma94/bazi-skill](https://github.com/jinchenma94/bazi-skill)，不以平行自创体系替代：

| Skill 资产 | Web 复用方式 |
|------------|--------------|
| `SKILL.md` 三阶段流程（收集→排盘→分析） | 产品主流程、表单步骤、报告章节一一对齐 |
| `references/wuxing-tables.md` | 排盘引擎常量与十神/藏干/干支关系表 |
| `references/shichen-table.md` | 时辰换算、五鼠遁起时 |
| `references/dayun-rules.md` | 大运顺逆、起运年龄、流年规则 |
| `references/classical-texts.md` | 规则模板条文 + LLM System Prompt 典籍约束 |
| 边界情况表 / 注意事项语气 | 引擎异常提示与全局文案规范 |

实现策略：

1. 仓库内保留 `.claude/skills/bazi` 为权威来源；构建时或开发时同步至 `src/lib/bazi/references`（只读）。
2. **排盘**：把 skill 中的表格与口诀**代码化**为确定性纯函数（可单测对照 skill 算例）。
3. **规则模板解读**：章节结构 = skill 第三阶段 1–8；条文优先引用 `classical-texts.md` 摘要，禁止另起一套断语体系。
4. **LLM 解读**：System Prompt 嵌入 skill 角色设定 + 九本典籍规则摘要 + 盘面 JSON；要求标注典籍出处风格，与 skill 输出规范一致；失败回落规则模板。
5. skill 上游更新时，优先 diff references 再改引擎/Prompt，避免产品与 skill 分叉。

## 3. 目标用户与场景

- **泛娱乐用户**：3 分钟拿到「我是谁、近年运势、事业感情健康建议」，术语有释义，可分享卡片。
- **命理爱好者**：可展开十神/藏干/格局/用神与典籍出处，对照原局与大运流年。
- **核心场景**：自测八字、帮亲友排盘（本地多档案）、截图/链接分享结果。

## 4. 信息架构与核心流程

### 4.1 页面

| 路由（示意） | 说明 |
|-------------|------|
| `/` | 落地页：价值主张、免责、开始排盘 |
| `/chart/new` | 引导式信息收集（对齐 skill Step 1–9） |
| `/chart/[id]` | 命盘主视图：四柱表、五行、大运、模式切换 |
| `/chart/[id]/reading` | 综合解读报告（模板 / LLM） |
| `/chart/[id]/calibrate` | 历史事件校准反馈 |
| `/share/[token]` | 只读分享页（脱敏可选） |
| `/settings` | 本地偏好：默认模式、真太阳时开关等 |

本地档案列表可放在首页或 `/charts`。

### 4.2 主用户旅程（对齐 bazi-skill）

```
落地 → 分步采集出生信息 → 信息确认 → 确定性排盘
  → 命盘可视化（默认通俗摘要）
  → 选择解读模式：规则模板 | LLM 典籍批命
  → 历史事件校准（3–5 条预测验证）→ 微调表述/强调点
  → 综合建议 → 生成分享链接 / 导出命盘卡片
```

### 4.3 信息收集字段（与 skill 对齐）

| 字段 | 必填 | 说明 |
|------|------|------|
| 姓名 | 是 | 展示与称呼 |
| 曾用名 / 改名年份 | 否 | 记录；解读可轻量提及 |
| 阳历生日 | 阳历或农历至少其一 | 精确到日 |
| 农历生日 | 同上 | 支持闰月标注 |
| 出生时间 / 时辰 | 否 | 未知则六字盘 |
| 性别 | 是 | 大运顺逆 |
| 出生地（省市） | 建议填 | 真太阳时 |
| 在世 / 已故及卒年 | 是 | 流年推算边界 |
| 当前分析基准日 | 默认今天 | 可改 |

确认页汇总后进入排盘（可回改）。

## 5. 功能规格（MVP）

### 5.1 专业排盘引擎（确定性）

- 年柱：立春分年
- 月柱：节气分月 + 年上起月
- 日柱：公历精确日柱（含夜子时规则说明）
- 时柱：时辰表 + 五鼠遁；未知时柱标「未知」
- 十神、藏干、干支关系（合冲刑害等可先展示核心）
- 大运：阴阳年 × 性别顺逆、起运年龄（节气天数/3）、十年一步
- 流年：当前年及近 1–3 年（已故截至卒年）
- **真太阳时**：按经度/出生地可选校正
- 边界：节气交界双月柱提示、立春前后提示、闰月以节气为准

输出结构化 JSON（供 UI 与两种解读共用）。

### 5.2 命盘可视化

- 四柱表格（天干/地支/十神/藏干）
- 五行力量条/雷达（通俗）
- 大运时间轴 + 当前大运高亮
- 流年条
- **通俗模式**：一句话日主画像 + 喜用方向白话
- **专业模式**：格局、用神忌神、典籍向标签

视觉：暗色底、金/电青强调、轻微噪点/网格、国风纹样与霓虹描边；桌面宽屏双栏（盘左文右），移动单栏分段。

### 5.3 解读双模式

| 模式 | 行为 |
|------|------|
| 规则模板 | 基于结构化盘面填充章节模板，语气中性建设性 |
| LLM | 服务端调用配置模型；Prompt 注入盘面 JSON + 典籍规则；禁止恐吓/医疗财务绝对断言 |

用户可对同一盘生成两种结果并切换对比。LLM 失败时自动回落模板并提示。

报告章节（对齐 skill 第三阶段）：

1. 日主强弱与性格倾向
2. 十神与六亲要点
3. 五行平衡与喜用
4. 格局判定
5. 大运
6. 流年
7. 历史事件校准题
8. 事业/财运/感情/健康建议 + 可选方位颜色

### 5.4 历史校准

- 系统给出 3–5 条「已发生时段 + 事件性质」假设
- 用户：准确 / 部分准确 / 不准 + 可选备注
- MVP：用反馈调整报告侧重文案（非重算排盘）；本地保存反馈

### 5.5 本地数据与分享

- localStorage / IndexedDB 存档案与报告
- 分享：服务端生成 token 只读快照；图片卡片（四柱 + 一句签语 + 链接）
- 预留用户 ID 字段，二期账号同步

### 5.6 合规与文案

- 全局免责声明
- 健康→就医、财务→理性决策
- 结束语：「命理分析仅供参考，人生在于自身的努力和选择。」

## 6. 技术架构（MVP）

```
Next.js (App Router) + TypeScript + Tailwind
├── app/                 UI 路由
├── components/          命盘、表单、报告、卡片
├── lib/bazi/            排盘引擎（纯函数、可单测）
│   ├── calendar/        节气、农历、日柱
│   ├── pillars/         四柱、十神、藏干
│   ├── dayun/           大运流年
│   └── solar-time/      真太阳时
├── lib/reading/         规则模板渲染
├── app/api/reading/     LLM 代理（服务端 Key）
├── app/api/share/       分享快照
└── references/          从 bazi-skill 同步的规则摘要（只读）
```

- 排盘：零 LLM，结果可复现、可测试
- 农历/节气：成熟开源库 + 用例对照 skill 规则
- LLM：OpenAI 兼容接口（BASE_URL + API_KEY + MODEL）
- 部署：Vercel / 任意 Node 主机

## 7. 非目标（仍不做 / 长期不做）

**MVP 与近中期路线图之外，明确不做：**

- 支付、会员付费墙（可先账号同步，变现另立项）
- 姓名学深度、奇门遁甲、太乙等其它术数（未入路线图）
- 原生 App（优先 PWA / 响应式 Web）
- 恐吓式断语、医疗/投资绝对断言
- 离线完整 LLM

> 原 MVP「不做账号 / 紫微 / 六爻」已升级为 **§12 产品路线图** 中的正式阶段，不再视为永久非目标。

## 12. 产品路线图（Post-MVP）

> 原则：**八字确定性引擎与合规语气为底座**；新术数同样「排盘可测 + 模板/LLM 解读」；账号优先解决同步与多端，再谈增长与变现。

### 12.1 阶段总览

```
[MVP 八字闭环] ──► P0 生产加固 ──► P1 账号体系
                      │                │
                      └──── 八字深化 ◄──┘
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
         P2 紫微斗数      P3 六爻占卜     P4 跨术数体验
              └───────────────┴───────────────┘
                              ▼
                    P5 增长与可选变现
```

| 阶段 | 名称 | 目标 | 依赖 | 预估量级 |
|------|------|------|------|----------|
| **P0** | 生产加固 | 可上线、分享不丢、防刷 | MVP | 小–中 |
| **P1** | 账号体系 | 登录、云端档案、多端同步 | P0 | 中 |
| **P1.5** | 八字深化 | 格局/用神/性别六亲/生产级分享图 | P0 | 中 |
| **P2** | 紫微斗数 | 排盘 + 可视化 + 解读 | P0；建议 P1 | 大 |
| **P3** | 六爻占卜 | 起卦 + 解卦 + 一事一问 | P0；建议 P1 | 中–大 |
| **P4** | 跨术数体验 | 统一档案、首页入口、合参（可选） | P1+P2 或 P3 | 中 |
| **P5** | 增长与变现 | 可选会员/额度（非必须） | P1 | 中 |

### 12.2 P0 · 生产加固（上线前）

| 项 | 说明 |
|----|------|
| 分享存储 | 替换 `data/shares.json` 为 KV / DB / Blob |
| 限流与鉴权 | 解读/分享 API 全局限流；敏感操作可挂登录 |
| 观测 | LLM 调用日志、错误率、成本指标 |
| 部署文档 | 环境变量、域名、备份与删除策略 |

### 12.3 P1 · 账号体系

| 项 | 说明 |
|----|------|
| **目标** | 用户可登录，命盘/报告/校准云端同步；**游客模式**全功能当次可用，结果仅 sessionStorage 暂存（关浏览器清空） |
| **登录方式（建议）** | 邮箱 Magic Link 或 OAuth（GitHub / 微信等按地区选型）；MVP 账号不做强制手机号 |
| **数据模型** | `User` ← `Profile/Chart/Report/Calibration`；现有 `USER_ID` / localStorage 迁移为「匿名会话 → 登录合并」 |
| **路由（示意）** | `/auth/login`、`/auth/callback`、`/account`、`/charts` 云端列表 |
| **权限** | 本人读写；分享链仍只读公开摘要 |
| **隐私** | 导出/删除账号数据；免责与隐私政策页 |
| **非目标（本阶段）** | 支付、团队空间、复杂 RBAC |

**验收：** 登录后换设备可见历史八字档案；登出后本地模式仍可排盘。

### 12.4 P1.5 · 八字深化（可与 P1 并行）

- 格局成格/败格、调候表扩展、合化条件  
- 解读分性别六亲、起运「岁+月」展示  
- 真 PNG/OG 分享图、五行雷达等体验打磨  

### 12.5 P2 · 紫微斗数

| 项 | 说明 |
|----|------|
| **定位** | 生辰命盘类，与八字并列的「整盘论命」；**非**一事一问 |
| **能力** | 排十二宫与主星/辅星（确定性引擎）；命宫身宫、大限流年；通俗/专业可视化；模板 + LLM 解读（典籍/流派规则摘要另建 `references` 或 skill） |
| **输入** | 与八字复用：姓名、性别、阳历/农历、时辰、出生地、真太阳时开关 |
| **路由（示意）** | `/ziwei/new`、`/ziwei/[id]`、`/ziwei/[id]/reading` |
| **引擎** | `src/lib/ziwei/**` 纯函数 + 金标准用例；禁止「只靠 LLM 排盘」 |
| **UI** | 赛博国潮一致；宫位盘 + 星曜列表；与八字档案可挂同一 `person`（需账号或本地 personId） |
| **合规** | 同八字：娱乐学习、中性建设性、结束固定句 |

**验收：** 同生辰多次排盘一致；爱好者可看主星落宫；报告章节结构固定可测。

### 12.6 P3 · 六爻占卜

| 项 | 说明 |
|----|------|
| **定位** | **一事一问**：起卦断事，非终身命盘 |
| **能力** | 铜钱/时间/手动指定起卦；本卦、变卦、世应、用神；动爻与变爻；模板解卦 + LLM（易理约束 Prompt） |
| **输入** | 所问事项（文本）、起卦方式、可选时空信息；**不强制**完整生辰 |
| **路由（示意）** | `/liuyao/new`、`/liuyao/[id]` |
| **引擎** | `src/lib/liuyao/**` 确定性装卦；卦辞/爻辞数据表驱动 |
| **体验** | 强调「针对本次所问」；历史问卦列表（登录后云端） |
| **合规** | 不替代决策；忌恐吓；大事建议理性与专业意见 |

**验收：** 同一装卦输入得相同卦象；用户能看懂本卦/变卦与一句话结论。

### 12.7 P4 · 跨术数体验

| 项 | 说明 |
|----|------|
| 首页 | 术数入口：八字 / 紫微 / 六爻 |
| 人物档案 | 一人多盘（八字+紫微）；六爻按「问事」归档 |
| 合参（可选） | 同人八字与紫微对照摘要（谨慎表述，避免互相打架式断言） |
| 品牌 | 总称「赛博命理」，子品牌保留赛博八字 / 赛博紫微 / 赛博六爻 |

### 12.8 P5 · 增长与可选变现

- LLM 次数额度、高清分享、云端空间等（可选）  
- 仍保持**免费本地排盘**底线，避免核心算盘能力完全上锁  

### 12.9 优先级建议（执行顺序）

1. **P0** 生产加固（否则分享/解读不宜公网）

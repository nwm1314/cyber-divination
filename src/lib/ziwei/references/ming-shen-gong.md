# 命宫 · 身宫 · 十二宫 · 五行局（三合）

> T101 权威表说明；实现见 `src/lib/ziwei/tables/constants.ts` 与 `palaces.ts`。

## 1. 安命身宫

- **寅起正月**，顺数至生月（正月落寅，二月卯…）。
- **逆数生时**为命宫；**顺数生时**为身宫。
- 时支序：子=0 … 亥=11。

实现索引（寅=0）：

```
monthIndex = lunarMonth - 1
mingYinIndex = (monthIndex - hourIndex) mod 12
shenYinIndex = (monthIndex + hourIndex) mod 12
```

## 2. 十二宫

自命宫**逆布**：命→兄→夫→子→财→疾→迁→仆(交友)→官→田→福→父。

## 3. 五虎遁宫干

年干起寅宫天干：

| 年干 | 寅宫干 |
|------|--------|
| 甲己 | 丙 |
| 乙庚 | 戊 |
| 丙辛 | 庚 |
| 丁壬 | 壬 |
| 戊癸 | 甲 |

自寅顺布天干。

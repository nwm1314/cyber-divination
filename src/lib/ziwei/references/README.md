# 紫微斗数 · 规则权威源（T100）

> 本目录为紫微**排盘与表数据**的权威说明与后续表文件落点。  
> **禁止**用 LLM 生成或「估算」星曜落宫、大限、流年；解读层（T104）才可模板/LLM。

## 1. 引擎策略（主 Agent 拍板）

| 项 | 决策 |
|----|------|
| 实现方式 | **自研表驱动 + 纯函数**（`src/lib/ziwei/**`） |
| 依赖 | **不**引入重型紫微 npm 包；日历可复用项目已有农历/节气能力 |
| 确定性 | 同输入 → 同输出（deep equal）；全部逻辑可单测 |
| LLM | **禁止参与排盘**；仅解读报告可用 |

## 2. 流派说明

- **默认流派：三合派**（常见安星顺序，见下）。
- 盘体/安星主流派为 **三合**（`meta.school = "sanhe"`，`meta.schools.core`）。
- 飞星飞宫为 **叠加命名空间**（`meta.schools.feixing`，`rulePriority` 含 `feixing.flights`），**不**替换三合主星安法。
- 年龄口径：`meta.agePolicy = "xusui"`（严格虚岁，T270）。
- 若日后支持多流派改安星，必须分表、分 `engineVersion` / `school`，不得混用。

### 2.1 三合派 · 常见安星顺序（说明级，非实现）

实现细节与查表在 **T101** 落地；此处仅锁顺序约定，避免实现分叉：

1. **定寅首 / 五行局**（月系与生年干支相关表）
2. **安命宫、身宫**（月支 + 时支）
3. **安十二宫**（自命宫逆布）
4. **安紫微星系**（紫微→逆安天机、太阳、武曲、天同、廉贞等）
5. **安天府星系**（天府→顺安太阴、贪狼、巨门、天相、天梁、七杀、破军）
6. **安辅曜**（文昌文曲、左辅右弼、天魁天钺、禄存擎羊等，按年干/时支等表）
7. **安四化**（生年干四化；自化等可后续扩展）
8. **大限 / 流年**（T102：命宫起大限，阳男阴女顺/逆等）

> 具体步数、起例以本目录后续 **表文件** 为准；表未就绪前不得用模型「补全」宫星。

# 紫微 · 天府星系（三合）

> 实现：`src/lib/ziwei/stars.ts`

## 1. 起紫微

农历日 + 五行局数：

- 日数 + offset 可被局数整除；offset 自 0 递增。
- 商 `q = floor((day+offset)/ju) % 12`；起始 `ziwei = q - 1`（寅起）。
- offset 偶：`ziwei += offset`；奇：`ziwei -= offset`；再 mod 12。

天府：`tianfu = (12 - ziwei) mod 12`（寅/申轴镜像：紫微寅则天府寅，紫微戌则天府午；**非**地支 +6 对冲）。

## 2. 紫微星系（逆）

紫微 → 天机 → (空) → 太阳 → 武曲 → 天同 → (空) → (空) → 廉贞

## 3. 天府星系（顺）

天府 → 太阴 → 贪狼 → 巨门 → 天相 → 天梁 → 七杀 → (空×3) → 破军

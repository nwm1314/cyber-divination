# 常用辅星安星（三合 · T160）

> 权威说明；实现见 `tables/aux-stars.ts`、`aux-stars.ts`。**禁止 LLM 补全。**

## 范围

本切片安 **13 颗**常用辅/煞：

| 类别 | 星 |
|------|-----|
| soft | 左辅、右弼、文昌、文曲、天魁、天钺、禄存 |
| harsh | 擎羊、陀罗、火星、铃星、地空、地劫 |

流昌流曲、截空见 `liuchang-jiekong.md`（T191/T192）。  
博士十二神见 `boshi.md`（T182，独立模块）。

## 安星规则摘要

| 星 | 依据 | 规则要点 |
|----|------|----------|
| 禄存 | 年干 | 甲寅乙卯丙巳丁午戊巳己午庚申辛酉壬亥癸子 |
| 擎羊 / 陀罗 | 禄存 | 羊 = 禄前一宫；陀 = 禄后一宫 |
| 天魁 / 天钺 | 年干 | 甲戊庚丑未；乙己子申；丙丁亥酉；壬癸卯巳；辛午寅 |
| 左辅 / 右弼 | 农历月 | 正月左辰右戌；月数顺辅逆弼 |
| 文昌 / 文曲 | 时支 | 昌：戌起子时逆；曲：辰起子时顺 |
| 火星 / 铃星 | 年支三合 + 时 | 寅午戌火丑铃卯；申子辰火寅铃戌；巳酉丑火卯铃戌；亥卯未火酉铃戌；再按时支顺行 |
| 地空 / 地劫 | 时支 | 亥起子时：空逆劫顺 |

索引约定：与主星相同，**寅起 0**。
